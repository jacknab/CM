# Stripe Standard account payouts

Accounts connected to Certxa through Stripe OAuth are **Standard / Stripe Dashboard** accounts. The salon owns its Stripe Dashboard and its payout schedule. Stripe's `payouts_enabled` means the account is eligible for bank payouts; it **does not** give Certxa platform controls to create payouts via the API. Stripe will reject a platform-initiated payout with “You cannot create payouts on behalf of this account.” No money is moved by that rejected request.

For an existing Standard account, sign into the **same connected Stripe account** and open [Stripe Dashboard → Payouts](https://dashboard.stripe.com/payouts) (or [test-mode payouts](https://dashboard.stripe.com/test/payouts)). You can manage the payout schedule and, where Stripe makes manual payouts available for your account, submit the payout there. Test-mode funds and payouts never reach a real bank account.

Certxa now links Standard-account owners to their Stripe Dashboard instead of offering an API payout button, and rejects direct payout API calls before sending them to Stripe. Express accounts created and controlled by the Certxa platform retain their in-app payout flow. If Certxa needs to initiate payouts for a Standard account, Stripe must explicitly enable **platform controls** for that account **and Certxa must update its account capability checks**; reconnecting or changing the database account type alone cannot grant that permission. Do not replace an existing connected account without planning for balances, transaction history, and any active Terminal readers.
