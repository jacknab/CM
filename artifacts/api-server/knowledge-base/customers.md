# Customer Management

## Overview
Certxa maintains a complete client database with visit history, contact info, preferences, and notes.

## Adding a New Client
- Go to Clients → New Client
- Enter name, phone, email (optional), and any notes
- Save — the client is now in your database

## Finding a Client
- Use the search bar at the top of the Clients page
- Search by name, phone number, or email
- Click on any result to open the full client profile

## Client Profile
Each client profile includes:
- Contact information (phone, email)
- Visit history (all past appointments)
- Upcoming appointments
- Total visits and revenue
- Loyalty points balance
- Membership status
- Notes and preferences

## Editing Client Info
- Open the client profile
- Click "Edit" to update name, phone, email, or notes
- Save changes

## Merging Duplicate Clients
If a client was created twice, contact support to merge their profiles. This combines visit history and loyalty points.

## Client Notes
Add permanent notes to a client profile (e.g., "Allergic to certain products", "Prefers Jennifer"). Notes are visible to all staff.

## Client Tags
Tag clients for easy filtering (e.g., "VIP", "Lapsed", "Referral"). Create custom tags in Settings.

## Exporting Clients
Export your entire client list to CSV from Clients → Export. Includes contact info and visit count.

## GDPR / Data Deletion
To permanently delete a client and their data, open the profile and select "Delete Client". This is irreversible.
