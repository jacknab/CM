# Appointments

## Overview
Certxa allows businesses to create, view, edit, and cancel appointments directly from the front desk or calendar view.

## Creating an Appointment
- Go to Front Desk or Calendar
- Click "New Appointment" or an open time slot
- Select the client (or create a new one)
- Choose the service, staff member, date, and time
- Click "Book" to confirm

## Editing an Appointment
- Click on any existing appointment in the calendar
- Update the service, time, staff, or notes
- Save changes — the client will receive an updated notification if SMS/email is enabled

## Cancelling an Appointment
- Open the appointment and click "Cancel"
- Optionally add a cancellation reason
- The slot is immediately freed for other clients

## Appointment Statuses
- **Pending** — booked but not yet confirmed
- **Confirmed** — confirmed by staff or auto-confirmed
- **Completed** — service has been performed
- **Cancelled** — appointment was cancelled
- **No Show** — client did not arrive

## No Show Handling
Mark clients as "No Show" from the appointment view. This is tracked in their client profile for reporting.

## Double Booking
Certxa prevents double-booking by default. If you need to allow it, contact support to enable the override setting.

## Walk-ins
Use the "Walk-in" button on the Front Desk page to quickly book a same-day appointment without going through the full booking flow.

## Recurring Appointments
Currently, appointments must be booked individually. Batch booking for recurring clients can be done by selecting the client and using the "Book Again" shortcut.
